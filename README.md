# 📊 Meta Ad Performance Dashboard

## 📌 Overview
An interactive **Power BI dashboard** designed to analyze Meta advertising performance across **Facebook and Instagram**.

## 🛠️ Tools Used
- Power BI
- Power Query
- DAX
- Data Modeling

## 📈 Key Metrics
- Impressions
- Clicks
- Engagements
- CTR
- Conversion Rate
- Purchase Rate
- Budget
- Purchases

## 🔍 Dashboard Analysis
- Performance by Facebook & Instagram
- Impressions by Age and Gender
- Country-wise performance
- Weekly and hourly trends
- Ad type analysis
- Campaign and interest filtering

## 🎯 Objective
To provide actionable insights into **ad performance, audience behavior, campaign effectiveness, and marketing trends** using Power BI.

**Power BI | DAX | Power Query | Data Modeling | Data Visualization | Data Analytics**
